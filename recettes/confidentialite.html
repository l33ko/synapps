Confidentialité

Recettes est une petite application gratuite de la collection SynApps, sans publicité ni pistage.

Ce qui est enregistré

  • Ton adresse e-mail, pour te connecter (sans mot de passe) et pour que les membres de ta famille sachent qui a ajouté une recette.
  • Tes familles : leur nom, leur code d’invitation et la liste de leurs membres.
  • Les recettes que vous ajoutez, avec la date et l’auteur de chaque ajout ou modification.

Aucune autre donnée n’est collectée : pas de statistiques, pas de cookies publicitaires.

Qui peut voir tes recettes

Uniquement les membres de ta famille, c’est-à-dire les personnes à qui vous avez donné le lien ou le code d’invitation. Cette règle est appliquée par la base de données elle-même. Un administrateur de la famille peut retirer un membre et changer le code d’invitation à tout moment.

Où sont les données

Les données sont stockées chez Supabase (base de données et connexion). Les e-mails de connexion sont envoyés par un service d’envoi d’e-mails. Lors d’un import depuis un lien, la page de la recette est lue par le serveur, et seule la recette extraite est enregistrée. Lors d’une recherche sur le web, les mots tapés (et rien d’autre : ni ton e-mail, ni tes recettes) sont transmis au moteur de recherche Brave Search pour trouver des recettes ; rien n’est enregistré tant que tu n’ajoutes pas une recette au carnet.

Tes droits

  • Exporter les recettes d’une famille : Mon compte → Exporter les recettes.
  • Quitter une famille : Famille → Quitter.
  • Supprimer ton compte et toutes tes données : Mon compte → Supprimer mon compte. La suppression est immédiate et définitive.

Recettes importées

Les recettes importées depuis un site restent la propriété de leurs auteurs. Elles sont gardées pour l’usage privé de ta famille, avec un lien vers la page d’origine, et ne sont jamais rendues publiques.
